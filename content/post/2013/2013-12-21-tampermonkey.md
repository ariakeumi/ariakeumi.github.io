<a title="点击下载greasemonkey" href="http://mozilla.com.cn/addon/14-greasemonkey/" target="_blank">Greasemonkey</a>，简称GM，俗称油猴子。

是一个Google员工开发的<a href="http://zh.wikipedia.org/wiki/Mozilla_Firefox" target="_blank">火狐</a>附加组件，它让用户安装一些脚本使大部分HTML为主的网页于用户端直接改变得更方便易用。[  
][2] 

在<a href="http://zh.wikipedia.org/wiki/Google_Chrome" target="_blank">Chrome</a>的油猴扩展程序叫<a title="点击下载Tampermonkey" href="https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo" target="_blank">Tampermonkey</a> (点击下载)。

安装完<a title="点击下载Tampermonkey" href="https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo" target="_blank">Tampermonkey</a>后，进入脚本分享网页点右上角的 &#8220;Install&#8221; 即可安装启动脚本。

&nbsp;

## <a href="http://userscripts.org/scripts/show/177191" target="_blank">百度云网盘大文件下载没限制，不用安装云管家</a>

这脚本名字就这么长。

这原理我也曾使用过，转存想要下载的大文件，然后用WAP模式打开自己的网盘就可以不需要第三方工具直接下载大文件了。

## <a href="http://userscripts.org/scripts/show/121261" target="_blank">Straight Google<br /> </a>

从 google 的搜索结果列表中去除重定向的操作，两个目的。

1. 避免 google 知道我点击了某个搜索结果

2. 对于某些敏感网站，google 的重定向会导致 google 自身被墙

## <a href="http://userscripts.org/scripts/show/175409" target="_blank">百度饼</a>

把百度首页改成Bing那样。

个人还是喜欢地址栏+Google。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-814" alt="baidu" src="https://wp-archive.baka.li/2013/12/baidu.jpg" width="600" height="351" />][3]

## <a href="http://userscripts.org/scripts/show/31057" target="_blank">defBackgroundUP</a>

修改网页背景颜色，绝大部分网页的都是白色背景的，可能会觉得背景过于刺眼。

有了它就可以把背景修改成自己喜欢的颜色啦！～

## <a href="http://userscripts.org/scripts/show/168404" target="_blank">Download YouTube Videos as MP4</a>

下载Youtube上的视频，就是Youtube有原生下载功能一样。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-807" alt="Download YouTube Videos as MP4" src="https://wp-archive.baka.li/2013/12/Download-YouTube-Videos-as-MP4.png" width="781" height="237" />][4]

##  <a href="http://www.colg.cn/thread-3424179-1-1.html" target="_blank">Discuz 屏蔽id</a>

眼不见心不烦，彻底屏蔽不想看到的人，适用于DZ搭建的论坛。

新浪微博也有类似的脚本。

## <a href="http://userscripts.org/scripts/show/182282" target="_blank">Discuz论坛长头像自定义无损上传</a>

据屋主测试DZ X3.1无效，X2可以。
