朋友为了玩FF14升级PC平台，然后把旧平台送我了，好朋友啊！！！

他的新平台：

> CPU i7-4790K
> 
> GPU GTX970
> 
> MB MSI Z97
> 
> RAM Kingston 8GB DDR3
> 
> SSD Toshiba 256GB
> 
> Power Antec Neo Eco 550M

送我的旧平台：

> CPU i5-2380P
> 
> GPU GTX550Ti
> 
> MB GA B75
> 
> RAM Corsair 4GB DDR3

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-3417" src="https://wp-archive.baka.li/2015/01/i5-gtx550ti-4gram-b75.jpg" alt="i5-gtx550ti-4gram-b75" width="1843" height="1382" srcset="https://wp-archive.baka.li/2015/01/i5-gtx550ti-4gram-b75.jpg 1843w, https://wp-archive.baka.li/2015/01/i5-gtx550ti-4gram-b75-150x112.jpg 150w, https://wp-archive.baka.li/2015/01/i5-gtx550ti-4gram-b75-300x225.jpg 300w, https://wp-archive.baka.li/2015/01/i5-gtx550ti-4gram-b75-1024x768.jpg 1024w" sizes="(max-width: 1843px) 100vw, 1843px" />][1]

得到新平台打算做的第一件事就是装上黑苹果，然后再玩GTA。以前的是Llano APU集显平台，装不了黑苹果，也玩不了GTA，虽然GTX550Ti也不一定能玩&#8230;

黑苹果对硬件要求很严格，技嘉的主板比较容易搞，但是我的是ITX机箱，还得再买了块技嘉1155接口的ITX板子。

1155的ITX板停产应该很久了，淘宝很少货，找到3个合适的。

二手GA-H67N-USB3-B3，价格325。

GA-B75N-WIFI，价格599。

GA-H77N-WIFI，价格599。

B75N-WIFI和H77N-WIFI主要是多了双网卡、无线网卡、蓝牙这些对我没用的功能，而且也不好驱动，大概&#8230;所以选了最便宜的二手H67。

ITX机箱装起来就是麻烦，线怎么理还是乱，把琴里扔进去。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-3414" src="https://wp-archive.baka.li/2015/01/new-PC-kotoli.jpg" alt="new-PC-kotoli" width="1728" height="2304" srcset="https://wp-archive.baka.li/2015/01/new-PC-kotoli.jpg 1728w, https://wp-archive.baka.li/2015/01/new-PC-kotoli-113x150.jpg 113w, https://wp-archive.baka.li/2015/01/new-PC-kotoli-225x300.jpg 225w, https://wp-archive.baka.li/2015/01/new-PC-kotoli-768x1024.jpg 768w" sizes="(max-width: 1728px) 100vw, 1728px" />][2]

在收到硬件前看了很多远景上黑苹果的帖子，先整理下比较重要的吧。

安装前：

<a href="http://bbs.pcbeta.com/viewthread-1494831-1-1.html" target="_blank">黑苹果新手引导, 常见疑难解答, 必要知识普及帖</a>

安装镜像：

<a href="http://bbs.pcbeta.com/viewthread-1550906-1-1.html" target="_blank">Yosemite 10.10 和 10.10.1 正式版 懒人版安装镜像 支持变色龙 Clover引导 支持虚拟机</a>

懒人版安装简单，合适我。

引导方法：

<a href="http://bbs.pcbeta.com/viewthread-1518901-1-1.html" target="_blank">Windows下使用变色龙r2378+ 引导 OS X 10.10 懒人版安装超详细完整图文通用教程</a>

<a href="http://bbs.pcbeta.com/viewthread-1518850-1-1.html" target="_blank">【变色龙】支持 10.10 的 Chameleon_2.3svn_r2529 Mac版+Win版+EFI_Tools</a>

Clover+EFI 好像很难，最终选择了变色龙+MRB引导安装， 使用EasyBCM添加wowpc.iso来安装变色龙引导，我用的是修改版的 Chameleon\_2.2svn\_r2402\_10.10\_CBv2_pkg+wowpc 。

详细安装方法：

<a href="http://bbs.pcbeta.com/viewthread-1169005-1-1.html" target="_blank">在 win7 / win8 下安装苹果系统 (懒人版)</a>

排错方法：

<a href="http://bbs.pcbeta.com/viewthread-863656-1-1.html" target="_blank">新手常见(五国)(-v图)错误解决(原版,破解kernel,补丁kext下载)</a>

分区，写入安装映像、安装引导这些很简单，教程写的也很清楚，也不会出什么错，就不放图了。

安装的时候才是麻烦。

第一次安装，遇到Pci Configuration Begin错误，安装上面帖子的排错方法Q18。启动时加入『-v npci=0×2000 或 npci=0×3000』依旧不行，在org.chameleon.Boot.plist 加入

<key>Kernel Flags</key>  
<string>npci=0×2000</string>

也不行，替换文件试了还是不行。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-3394" src="https://wp-archive.baka.li/2015/01/205422t1ja4scq4zgseg1c.jpg.thumb_.jpg" alt="205422t1ja4scq4zgseg1c.jpg.thumb" width="640" height="478" srcset="https://wp-archive.baka.li/2015/01/205422t1ja4scq4zgseg1c.jpg.thumb_.jpg 640w, https://wp-archive.baka.li/2015/01/205422t1ja4scq4zgseg1c.jpg.thumb_-150x112.jpg 150w, https://wp-archive.baka.li/2015/01/205422t1ja4scq4zgseg1c.jpg.thumb_-300x224.jpg 300w" sizes="(max-width: 640px) 100vw, 640px" />][3]

各种方法试了无数次还是不行，整个人都快崩溃了，最后确定放弃安装Yosemite，去安装OS X Mavericks试试，然后安装很顺利很快就搞定了。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-3398" src="https://wp-archive.baka.li/2015/01/OS-X-Mavericks.jpg" alt="OS X Mavericks" width="1920" height="1080" srcset="https://wp-archive.baka.li/2015/01/OS-X-Mavericks.jpg 1920w, https://wp-archive.baka.li/2015/01/OS-X-Mavericks-150x84.jpg 150w, https://wp-archive.baka.li/2015/01/OS-X-Mavericks-300x169.jpg 300w, https://wp-archive.baka.li/2015/01/OS-X-Mavericks-1024x576.jpg 1024w" sizes="(max-width: 1920px) 100vw, 1920px" />][4]

显卡原生驱动，声卡没驱动，然后搞着搞着又进不了系统了，一怒下继续装Yosemite！

接着又是遇到那个错误，重复着搜索『Pci Configuration Begin』等关键词，终于爬到一张英文帖子。

其中一条回复，把10.9.5的的AppleACPIPlataform.kext替换进去，应该是这个意思吧。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-3399" src="https://wp-archive.baka.li/2015/01/yosemite-Pci-Configuration-Begin.png" alt="yosemite-Pci Configuration Begin" width="959" height="405" srcset="https://wp-archive.baka.li/2015/01/yosemite-Pci-Configuration-Begin.png 959w, https://wp-archive.baka.li/2015/01/yosemite-Pci-Configuration-Begin-150x63.png 150w, https://wp-archive.baka.li/2015/01/yosemite-Pci-Configuration-Begin-300x127.png 300w" sizes="(max-width: 959px) 100vw, 959px" />][5]

我试着做，搜到10.9.5的AppleACPIPlataform.kext，替换进去，结果让人激动，跳过了PCI错误。

接着，新的错误又出现了。

NVDRstartup:Official 后黑屏了，只能强制关机。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-3401" src="https://wp-archive.baka.li/2015/01/NVdastartup1.jpg" alt="NVdastartup" width="1296" height="967" srcset="https://wp-archive.baka.li/2015/01/NVdastartup1.jpg 1296w, https://wp-archive.baka.li/2015/01/NVdastartup1-150x112.jpg 150w, https://wp-archive.baka.li/2015/01/NVdastartup1-300x224.jpg 300w, https://wp-archive.baka.li/2015/01/NVdastartup1-1024x764.jpg 1024w" sizes="(max-width: 1296px) 100vw, 1296px" />][6]

进入Windows找到S\L\E下的NVDRstartup.kext删掉（备份好，安装完成还要替换回去才能驱动显卡），继续尝试进安装界面。

结果奇迹般的成功了，很顺利的安装了，安装完成后需要进入Windows复制文件，但是这时候是进不了Windows的，需要进PE用DiskGenius激活Win分区，我激活系统分区还是进不了，激活300M左右的那个系统保留分区就能进了。

把安装分区Extra目录复制到OS X系统分区目录下，然后重启 -v -f 进入设置向导界面。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-3403" src="https://wp-archive.baka.li/2015/01/OSX-Setup-Wizard.jpg" alt="OSX-Setup Wizard" width="1296" height="967" srcset="https://wp-archive.baka.li/2015/01/OSX-Setup-Wizard.jpg 1296w, https://wp-archive.baka.li/2015/01/OSX-Setup-Wizard-150x112.jpg 150w, https://wp-archive.baka.li/2015/01/OSX-Setup-Wizard-300x224.jpg 300w, https://wp-archive.baka.li/2015/01/OSX-Setup-Wizard-1024x764.jpg 1024w" sizes="(max-width: 1296px) 100vw, 1296px" />][7]

设置完成系统就安装好了，接下来搞驱动。

用Multibeast，参照自己的硬件勾选然后安装重启就可以了。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-3406" src="https://wp-archive.baka.li/2015/01/MultiBeast-yosemite1.png" alt="MultiBeast-yosemite" width="913" height="740" srcset="https://wp-archive.baka.li/2015/01/MultiBeast-yosemite1.png 913w, https://wp-archive.baka.li/2015/01/MultiBeast-yosemite1-150x122.png 150w, https://wp-archive.baka.li/2015/01/MultiBeast-yosemite1-300x243.png 300w" sizes="(max-width: 913px) 100vw, 913px" />][8]

声卡、网卡、USB3.0、SSD TRIM都成功搞定。

只有显卡驱动失败，3M显存，鼠标移动都卡出翔的感觉。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-3404" src="https://wp-archive.baka.li/2015/01/Yosemite-GPU.jpg" alt="Yosemite-GPU" width="1026" height="766" srcset="https://wp-archive.baka.li/2015/01/Yosemite-GPU.jpg 1026w, https://wp-archive.baka.li/2015/01/Yosemite-GPU-150x112.jpg 150w, https://wp-archive.baka.li/2015/01/Yosemite-GPU-300x224.jpg 300w, https://wp-archive.baka.li/2015/01/Yosemite-GPU-1024x765.jpg 1024w" sizes="(max-width: 1026px) 100vw, 1026px" />][9]

编辑变色龙的引导文件，开启显卡侦测，成功识别显卡。

但是分辨率、双显示器什么的都弄不了，还是一样卡顿。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-3407" src="https://wp-archive.baka.li/2015/01/Yosemite-Gpu-info.png" alt="Yosemite-Gpu-info" width="591" height="360" srcset="https://wp-archive.baka.li/2015/01/Yosemite-Gpu-info.png 591w, https://wp-archive.baka.li/2015/01/Yosemite-Gpu-info-150x91.png 150w, https://wp-archive.baka.li/2015/01/Yosemite-Gpu-info-300x183.png 300w" sizes="(max-width: 591px) 100vw, 591px" />][10]

然后我用Kext Wizard修改权限，重建缓存，执行然后重启。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-3408" src="https://wp-archive.baka.li/2015/01/Kext-Wizard.png" alt="Kext Wizard" width="569" height="574" srcset="https://wp-archive.baka.li/2015/01/Kext-Wizard.png 569w, https://wp-archive.baka.li/2015/01/Kext-Wizard-150x150.png 150w, https://wp-archive.baka.li/2015/01/Kext-Wizard-297x300.png 297w, https://wp-archive.baka.li/2015/01/Kext-Wizard-80x80.png 80w" sizes="(max-width: 569px) 100vw, 569px" />][11]

最后，终于解脱成功了，硬件基本都驱动起来了。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-3410" src="https://wp-archive.baka.li/2015/01/mac-osx-10.10-Yosemite-cool.jpg" alt="mac-osx-10.10-Yosemite-cool" width="1920" height="1080" srcset="https://wp-archive.baka.li/2015/01/mac-osx-10.10-Yosemite-cool.jpg 1920w, https://wp-archive.baka.li/2015/01/mac-osx-10.10-Yosemite-cool-150x84.jpg 150w, https://wp-archive.baka.li/2015/01/mac-osx-10.10-Yosemite-cool-300x169.jpg 300w, https://wp-archive.baka.li/2015/01/mac-osx-10.10-Yosemite-cool-1024x576.jpg 1024w" sizes="(max-width: 1920px) 100vw, 1920px" />][12]

以为这样完了，但是最后的最后我确定了，我这张技嘉的 H67N-UBS3-B3 竟然会啸叫，而且声音还不小，深夜的时候根本无法静下心来！

关掉了CPU节能选项，声音终于没了，但是睿频就没了，不甘心。

过两天退了这块主板入那块GA-H77N-WIFI吧。

累死了&#8230;休息。
