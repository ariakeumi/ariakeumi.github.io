最近亚马逊把 AWS EC2 实例的免费流量从每月 15GB 提高到了 100GB ，对于流量需求不高的用户，白嫖 AWS 搭梯子或者小博客是不错的选择。

新注册用户可以免费开12个月的特定的 EC2 实例。

只需要一张外币信用卡和一个美国手机号接验证码，我用的是 Google Voice。

注册很简单，不像 GCP、甲骨文和 Azure 一堆风控，直接真实信息就行，基本都能过，这里就不详写了。

### 创建实例 

注册完选择喜欢的区域创建 EC2 实例（可随意换区），系统选择 Debian 10 。

<img loading="lazy" decoding="async" width="904" height="847" src="https://wp-archive.baka.li/2022/04/AWS-1.png" alt="" class="wp-image-6129" />  

实例选择 t.2.micro ，免费的会注明 [ 支持免费套餐 ] 。

<img loading="lazy" decoding="async" width="904" height="510" src="https://wp-archive.baka.li/2022/04/AWS-2.png" alt="" class="wp-image-6130" />  

然后创建新密钥对，名称随意，私钥格式选 .pem ，把私钥下载到本地。

<img loading="lazy" decoding="async" width="908" height="460" src="https://wp-archive.baka.li/2022/04/AWS-3.png" alt="" class="wp-image-6131" />  <img loading="lazy" decoding="async" width="733" height="726" src="https://wp-archive.baka.li/2022/04/AWS-4.png" alt="" class="wp-image-6133" /> 

硬盘调到 30GB。

<img loading="lazy" decoding="async" width="933" height="418" src="https://wp-archive.baka.li/2022/04/AWS-5-1.png" alt="" class="wp-image-6134" />  

### 登录和调试 

接着创建实例，实例启动后，进控制台复制公网 IP 地址，用 SSH 登录。

这里我用的是 FinalShell ，认证方式选公钥，用户名填 admin ，导入刚才创建的私钥后登录。

<img loading="lazy" decoding="async" width="606" height="572" src="https://wp-archive.baka.li/2022/04/aws-ssh-login.png" alt="" class="wp-image-6135" />  

登录后先开启 BBR ，依次输入下面的几条命令，最后能看到 BBR 进程就说明开启成功。

<pre class="wp-block-code"><code>sudo -i
echo "net.core.default_qdisc=fq" &gt;&gt; /etc/sysctl.conf
echo "net.ipv4.tcp_congestion_control=bbr" &gt;&gt; /etc/sysctl.conf
sysctl -p
sysctl net.ipv4.tcp_available_congestion_control
lsmod | grep bbr</code></pre>

如果不想用私钥登录改成密码登录，输入以下命令创建带密码的 root 用户并允许密码登录。

<pre class="wp-block-code"><code>echo root:your_password|sudo chpasswd root
sudo sed -i 's/^#\?PermitRootLogin.*/PermitRootLogin yes/g' /etc/ssh/sshd_config;
sudo sed -i 's/^#\?PasswordAuthentication.*/PasswordAuthentication yes/g' /etc/ssh/sshd_config;
sudo service sshd restart</code></pre>
