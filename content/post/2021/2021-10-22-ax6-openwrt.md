<https://www.right.com.cn/forum/thread-4560135-1-1.html>

<a href="https://qust.me/post/hong-mi-ax6-jie-suo-ssh-an-zhuang-shi-yong-shellclash-jiao-cheng/" target="_blank" rel="noreferrer noopener">https://qust.me/post/hong-mi-ax6-jie-suo-ssh-an-zhuang-shi-yong-shellclash-jiao-cheng/</a>

<https://www.right.com.cn/forum/thread-4111331-1-1.html>

固件来自： <a href="https://www.right.com.cn/forum/forum.php?mod=viewthread&tid=5426438&extra=page%3D1%26filter%3Dtypeid%26typeid%3D64" target="_blank" rel="noreferrer noopener">https://www.right.com.cn/forum/forum.php?mod=viewthread&tid=5426438&extra=page%3D1%26filter%3Dtypeid%26typeid%3D64</a> 。

需要准备另外一台刷了 OpenWrt 的无线路由器（软路由不行），一台电脑，和下载链接里固件和工具: <a href="https://pan.baidu.com/s/1NwnFRVkgHpwkKAm_3vjAtA" target="_blank" rel="noreferrer noopener">https://pan.baidu.com/s/1NwnFRVkgHpwkKAm_3vjAtA</a> 提取码: i21k 。

  * 1. 登录红米 AX6 路由器后台给把官方固件降级到 1.0.18（miwifi\_ra69\_firmware\_45a77\_1.0.18.bin）。

  * 2. 电脑连接 OpenWrt 无线路由器，用 WinSCP 登录 OpenWrt 无线路由器把破解脚本上传到 /tmp 目录，然后 SSH 登录路由器执行下面的命令运行脚本。

<pre class="wp-block-code"><code>sh /tmp/wireless.sh</code></pre>

  * 3. 红米 AX6 路由器有线连接到电脑，登录路由器的 Web 后台，复制浏览器地址栏链接中的 stok（stok=和/之中的字符），然后在浏览器输入下面的链接回车。

<pre class="wp-block-code"><code>
http:&#47;&#47;AX6路由器的IP/cgi-bin/luci/;stok=刚刚复制的stok/api/misystem/extendwifi_connect?ssid=MEDIATEK-ARM-IS-GREAT&password=ARE-YOU-OK</code></pre>

成功会返回 code 0 ，再次在<span style="font-size: revert; color: initial;">浏览器输入下面的 URL 回</span>车，继续返回 code 0 。

<pre class="wp-block-code"><code>http:&#47;&#47;AX6路由器的IP/cgi-bin/luci/;stok=刚刚复制的stok/api/xqsystem/oneclick_get_remote_token?username=xxx&password=xxx&nonce=xxx</code></pre>

然后在AX6 路由器 Web 后台的 路由状态 界面，可以点击查看到 5GHz 频段的 WIFI 密码，这个 WIFI 密码变成 root 密码，复制它。

  * 4. SSH 登录 AX6 路由器（账号 root ，密码是刚才复制的），执行下面的两条命令。

<pre class="wp-block-code"><code>mkdir /tmp/syslogbackup/
dd if=/dev/mtd9 of=/tmp/syslogbackup/mtd9</code></pre>

接着在浏览器输入下面的链接下载备份。

<pre class="wp-block-code"><code>http:&#47;&#47;AX6路由器的IP/backup/log/mtd9</code></pre>

  * 6. 将 ax3000.sh 和 fuckax3000 两个文件通过 WinSCP （账号密码同SSH）上传到 AX6 路由器的 /etc 目录。

接着通过 SSH 登录执行：

<pre class="wp-block-code"><code>sh /etc/ax3000.sh unlock</code></pre>

执行后路由器自动重启，再次 SSH 登录执行：

<pre class="wp-block-code"><code>sh /etc/ax3000.sh hack</code></pre>

继续自动重启。

  * 7. 重启后 SSH 登录路由器，一条一条执行下面的命令。

<pre class="wp-block-code"><code>nvram set flag_last_success=0
nvram set flag_boot_rootfs=0
nvram set flag_boot_success=1
nvram set flag_try_sys1_failed=0
nvram set flag_try_sys2_failed=0
nvram set boot_wait=on
nvram set uart_en=1
nvram set telnet_en=1
nvram set ssh_en=1
nvram commit</code></pre>

  * 8. 通过 WinSCP 把 xiaomimtd12.bin （QSDK固件）上传到 AX6 路由器的 /tmp 目录，SSH执行：

<pre class="wp-block-code"><code>mtd write /tmp/xiaomimtd12.bin rootfs</code></pre>

  * 9. 拨电源重新启动路由器，浏览器打开 192.168.1.1 ，看到 OpenWrt 的登录界面就表示成功了，默认密码是 admin 。

接着用 WinSCP 把固件 a6minbib.bin 上传路由器到 /tmp 目录，SSH 执行下面的两条命令 。

<pre class="wp-block-code"><code>. /lib/upgrade/platform.sh
switch_layout boot; do_flash_failsafe_partition a6minbib "0:MIBIB"</code></pre>

执行完毕后拔电源重启路由器。

  * 10. 再次通过 WinSCP 把最终要刷的 OpenWrt 固件 openwrt-ipq807x-generic-redmi_ax6-squashfs-nand-factory.ubi 上传到 /tmp 目录，然后 SSH 执行下面几条命令。

<pre class="wp-block-code"><code>ubiformat /dev/mtd13 -y -f /tmp/openwrt-ipq807x-generic-redmi_ax6-squashfs-nand-factory.ubi
fw_setenv flag_last_success 1
fw_setenv flag_boot_rootfs 1
reboot</code></pre>

重启后就大功告成了，默认IP是 192.168.10.1 ，登录密码是 password 。

<img loading="lazy" decoding="async" width="1293" height="765" src="https://wp-archive.baka.li/2021/10/AX6-OpenWrt-Luci.png" alt="" class="wp-image-5944" />  

感叹下，AX6 上的这颗高通 IPQ8071A 真的强，刷上 OpenWrt 如虎添翼，能满足绝大部分人的需求的，不必再追求什么软路由了。

<img loading="lazy" decoding="async" width="1075" height="793" src="https://wp-archive.baka.li/2021/10/AX6-Speedtest.png" alt="" class="wp-image-5953" />  

后事，还记得那台帮助刷固件的 OpenWrt 无线路由器吗，执行完脚本后它会被更改网络设置，关掉 DHCP 服务和修改 WIFI SSID 及密码。

你还需要把连上它把电脑 IP 改成 169.254.31.2 ，子网掩码 255.255.255.0 ，网关 169.254.31.1 ，然后登录 169.254.31.1 把 LAN IP 和 WIFI设置改回来以及开启 DHCP 服务。
