Xposed Framwork 是Android系统一款可以在不修改APK的情况下影响程序运行（修改系统）的框架服务，基于它可以制作出许多功能强大的模块，且在功能不冲突的情况下同时运作。

作者是<a title="查看作者资料" href="http://forum.xda-developers.com/member.php?u=4419114" target="_blank">rovo98</a>，在<a href="http://forum.xda-developers.com/showthread.php?t=1574401" target="_blank">XDA的开发帖子</a>，<a href="https://github.com/rovo89/XposedBridge/wiki/Development-tutorial" target="_blank">Github主页</a>。

## <a href="http://repo.xposed.info/module/de.robv.android.xposed.installer" target="_blank">Xposed Installer</a> （官网页面下载） {#page-title}

下载安装后，点“框架” &#8211; “安装/更新” ，然后授权，重启就安装完成了。

<span style="color: #ff0000;">注意：Xposed只支持Android 4.0.3以上版本，还需要ROOT权限，暂不支持Android 4.4的ART模式。</span>

安装好了还需要在“模块”里激活Xposed模块应用。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-1393" src="https://wp-archive.baka.li/2014/01/Xposed-1.jpg" alt="Xposed-1" width="600" height="422" srcset="https://wp-archive.baka.li/2014/01/Xposed-1.jpg 600w, https://wp-archive.baka.li/2014/01/Xposed-1-150x105.jpg 150w, https://wp-archive.baka.li/2014/01/Xposed-1-300x211.jpg 300w" sizes="(max-width: 600px) 100vw, 600px" />][2]

自带的模块库，可以检查更新和下载。或者在<a href="http://repo.xposed.info/module-overview" target="_blank">Web模块库</a>下载。

## <a title="点击进入下载页面" href="http://repo.xposed.info/module/com.ceco.gm2.gravitybox" target="_blank">GravityBox</a> (JB，Android 4.1、4.2、4.3)

重力工具箱，神器，作者是<a title="XDA个人资料" href="http://forum.xda-developers.com/member.php?u=5008415" target="_blank">C3C076</a>，XDA大神。

亲儿子有了它就不需要再刷<a title="CyanogenMod官网" href="http://www.cyanogenmod.org/" target="_blank">CM</a>或者<a title="AOKP官网" href="http://aokp.co/" target="_blank">AOKP</a>了。

它拥有比CM更强大了自定义设置功能，堪比AOKP。

比如在JB机器里使通知栏和虚拟按键透明化，修改通知栏的各种图标字体颜色、虚拟按键颜色，在通知栏显示流量监控，把时钟显示在通知栏中间（IOS那样），实体按键功能也可以修改。

功能太强大了我就不多说了，要是能像AOKP那样修改虚拟按键图标就好了。

这个软件还有个<a href="http://www.android.com/versions/kit-kat-4-4/" target="_blank">KitKat</a>(Android 4.4)的版本，<a title="点击进入下载页面" href="http://repo.xposed.info/module/com.ceco.kitkat.gravitybox" target="_blank">GravityBox [KK]</a>，增加了屏幕录制等功能。

## <a title="点击进入下载页面" href="https://play.google.com/store/apps/details?id=com.oasisfeng.greenify" target="_blank">Greenify</a>

绿色守护，Android上著名的省电应用，一晚掉电5%不是梦。作者是<a title="作者的G+" href="https://plus.google.com/+OasisFeng/posts" target="_blank">Oasis Feng</a>，中国人。

『绿色守护』帮助你甄别那些对系统全局性能和耗电量有不良影响的应用程序，并通过独特的『绿色化』技术，阻止它们消耗您的电池电量，占用您的宝贵内存。经过『绿色化』工艺处理的应用，在您没有主动启动它们的时候，无法『偷偷』运行，而在您正常启动它们时仍然拥有完整的功能和体验，正如iPhone应用那样！

<span style="color: #ff0000;"><b>请勿『绿色化』闹钟、即时通讯、启动器类的应用，除非你不常使用它们，也不再依赖其后台功能（比如定时任务、消息推送等）。请务必确认经过『绿色化』处理的应用没有丧失任何您认为重要的后台机制。</b></span>

<span style="color: #000000;">部分是实验性特性需要在Xposed框架上激活才能使用，捐赠版能获得更多实验性特性。</span>

## <a title="下载链接" href="http://repo.xposed.info/module/tw.fatminmin.xposed.minminguard" target="_blank">MinMinGuard</a>

作者是<a title=" FatMinMin的XDA" href="http://forum.xda-developers.com/member.php?u=4981793" target="_blank">FatMinMin</a>，这个软件和<a href="http://sufficientlysecure.org/index.php/adaway/" target="_blank">AdAway</a>以及<a href="https://www.google.com.hk/url?sa=t&rct=j&q=&esrc=s&source=web&cd=1&cad=rja&ved=0CCsQFjAA&url=%68%74%74%70%73%3a%2f%2f%61%64%62%6c%6f%63%6b%70%6c%75%73%2e%6f%72%67%2f%7a%68%5f%43%4e&ei=rV3eUpS4LunZigf6l4GIDw&usg=AFQjCNGFEYshH_jDY5FpJYRkMJfnNpyXOg" target="_blank">Adblock</a>用的是完全不同的方法，透过Xposed framwork可以直接针对的API呼叫进行拦截，并且将广告所占看空间完全移除(参考比较图)，比起<a href="http://sufficientlysecure.org/index.php/adaway/" target="_blank">AdAway</a>和<a href="https://www.google.com.hk/url?sa=t&rct=j&q=&esrc=s&source=web&cd=1&cad=rja&ved=0CCsQFjAA&url=%68%74%74%70%73%3a%2f%2f%61%64%62%6c%6f%63%6b%70%6c%75%73%2e%6f%72%67%2f%7a%68%5f%43%4e&ei=rV3eUpS4LunZigf6l4GIDw&usg=AFQjCNGFEYshH_jDY5FpJYRkMJfnNpyXOg" target="_blank">Adblock</a>更有效率且不会偷跑背景程序。

这是一个开源程序，Github上的<a href="https://github.com/chiehmin/MinMinGuard" target="_blank">MinMinGuard源代码</a>，

关于这个软件的更多资讯和制作原理可以到作者在xda上面发的帖子观看 http://forum.xda-developers.com/showthread.php?t=2597332

## <a title="点击进入下载页面" href="http://repo.xposed.info/module/de.defim.apk.bootmanager" target="_blank">BootManager</a> {#page-title}

启动管理器，这个没什么好说的，禁止软件自启动。

不会有进程和服务，所以不要担心用了这些Xposed框架的软件会影响系统流畅和占内存。
