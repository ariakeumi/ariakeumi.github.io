## <a title="Google Play" href="https://play.google.com/store" target="_blank" rel="noopener">Google Play</a> & <a href="http://www.coolapk.com/apk/com.coolapk.market" target="_blank" rel="noopener">酷市场</a>

Play Store 无论设计还是使用体验都是最好的应用市场，可惜被墙，翻墙的话下载速度又比较慢，另外吐槽 App Store 真是难用死了，

酷市场则是国内最良心的应用市场，没事刷刷酷市场能发现很多新奇好玩的软件。

如果一款软件另有捐赠版/付费版，酷市场下载不了，但是评论里面都会有热心酷友给出捐赠版/付费版的下载链接，所谓同性交友网站&#8230;

## <a href="http://www.coolapk.com/apk/com.maxmpz.audioplayer" target="_blank" rel="noopener">PowerAMP</a>

Android上音质最好的音频播放器之一，音效也是一流强悍。

这是我第一个舍得花钱买的软件，价格3.99刀，主要是破解比较麻烦&#8230;

我使用了一个叫 <a title="去Google Play下载" href="https://play.google.com/store/apps/details?id=com.ikorolkov.poweramp.skins.ics" target="_blank" rel="noopener">Poweramp skin KitKat/JB/ICS</a> 的皮肤，有 Kitkat 的导航栏通知栏渐变阴影，播放界面呈现专辑封面的高斯模糊特效，非常漂亮。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-4105" src="https://wp-archive.baka.li/2014/02/Android-poweramp-2015.jpg" alt="Android-poweramp-2015" width="360" height="640" srcset="https://wp-archive.baka.li/2014/02/Android-poweramp-2015.jpg 360w, https://wp-archive.baka.li/2014/02/Android-poweramp-2015-84x150.jpg 84w, https://wp-archive.baka.li/2014/02/Android-poweramp-2015-169x300.jpg 169w" sizes="(max-width: 360px) 100vw, 360px" />][4]

## <a title="去Google Play下载" href="https://play.google.com/store/apps/details?id=com.lonelycatgames.Xplore" target="_blank" rel="noopener">X-Plore File Manager</a>

貌似 Android 最流行的文件管理器叫<a href="http://www.estrongs.com/" target="_blank" rel="noopener">E.S管理器</a>，好吧，我觉得E.S一点都不好用。

用过 Symbian 系统都该知道大名鼎鼎的 X-Plore 吧，它竟然还有 Android 版。

<!--more-->

Android采用了双窗格树形界面，操作效率高。

可以连接 Google Dirve、Dropbox 和 OneDrive 等国外知名网盘，还有 SSH、局域网、FTP 和 Picasa 相册访问等功能。
