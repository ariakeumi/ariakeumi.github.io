> Ubuntu是一个自由、开源、基于Debian的Linux发行版，发行周期为6个月，由 Canonical 公司和自由软件社区开发。 

不玩游戏、不使用专业大型软件、非程序员用户，试下看能不能用Ubuntu系统代替Windows。

## <a title="教程" href="http://jingyan.baidu.com/article/e3c78d6460e6893c4c85f5b1.html" target="_blank">EFI下Win 8.1+Ubuntu 14.04安装教程</a>

参照上面的教程EFI + GPT安装 Windows 8.1 / Ubuntu 14.04 双系统。 只需要一个U盘，很简单，引导是这样的。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-2880" src="https://wp-archive.baka.li/2014/08/ubuntu-boot.jpg" alt="ubuntu-boot" width="1280" height="960" srcset="https://wp-archive.baka.li/2014/08/ubuntu-boot.jpg 1280w, https://wp-archive.baka.li/2014/08/ubuntu-boot-150x112.jpg 150w, https://wp-archive.baka.li/2014/08/ubuntu-boot-300x225.jpg 300w, https://wp-archive.baka.li/2014/08/ubuntu-boot-1024x768.jpg 1024w" sizes="(max-width: 1280px) 100vw, 1280px" />][1] Ubuntu的桌面，左边是启动器，状态栏在顶部，这种布局在16:9的显示器下看着很舒服，因为感觉视野大了很多，然后我把Windows的任务栏也固定在左侧了。

壁纸换成了星空图（自带的），很有Mac OS X的感觉。

可以用和Win类似的Win键 + 数字键打开任务栏（启动器）的程序。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-2881" src="https://wp-archive.baka.li/2014/08/ubuntu-Desktop.jpg" alt="ubuntu-Desktop" width="1280" height="720" srcset="https://wp-archive.baka.li/2014/08/ubuntu-Desktop.jpg 1280w, https://wp-archive.baka.li/2014/08/ubuntu-Desktop-150x84.jpg 150w, https://wp-archive.baka.li/2014/08/ubuntu-Desktop-300x168.jpg 300w, https://wp-archive.baka.li/2014/08/ubuntu-Desktop-1024x576.jpg 1024w" sizes="(max-width: 1280px) 100vw, 1280px" />][2] 版本号14.04 LTS，14.04代表是2014年04月发布，LTS表示长期支持，发布后18个月内的支持。

设备名 Abyss Gundam，深渊高达 ZGMF-X31S /RGX-02，出自机动战士高达SEED DESTINY，我的智能设备都用高达里面的机体命名，略<del>中二</del>。 [<img loading="lazy" decoding="async" class="alignnone size-full wp-image-2896" src="https://wp-archive.baka.li/2014/08/ubuntu-Version.png" alt="ubuntu-Version" width="850" height="472" srcset="https://wp-archive.baka.li/2014/08/ubuntu-Version.png 850w, https://wp-archive.baka.li/2014/08/ubuntu-Version-150x83.png 150w, https://wp-archive.baka.li/2014/08/ubuntu-Version-300x166.png 300w" sizes="(max-width: 850px) 100vw, 850px" />][3]

这个叫什么来着&#8230;可以搜索本地和网络的内容，甚至Wikipedia，按Win键（Super L）呼出。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-2893" src="https://wp-archive.baka.li/2014/08/ubuntu-search.jpg" alt="ubuntu-search" width="1141" height="640" srcset="https://wp-archive.baka.li/2014/08/ubuntu-search.jpg 1141w, https://wp-archive.baka.li/2014/08/ubuntu-search-150x84.jpg 150w, https://wp-archive.baka.li/2014/08/ubuntu-search-300x168.jpg 300w, https://wp-archive.baka.li/2014/08/ubuntu-search-1024x574.jpg 1024w" sizes="(max-width: 1141px) 100vw, 1141px" />][4] Ubuntu的软件中心，里面的东西少的可怜，排版也不好。

其实我在想，要是Windows中也有软件中心该多好（Metro那个渣渣商店不算啊），一个MS帐号同步所有安装的软件。[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-2882" src="https://wp-archive.baka.li/2014/08/ubuntu-Software-Center.png" alt="ubuntu-Software-Center" width="1200" height="828" srcset="https://wp-archive.baka.li/2014/08/ubuntu-Software-Center.png 1200w, https://wp-archive.baka.li/2014/08/ubuntu-Software-Center-150x103.png 150w, https://wp-archive.baka.li/2014/08/ubuntu-Software-Center-300x207.png 300w, https://wp-archive.baka.li/2014/08/ubuntu-Software-Center-1024x706.png 1024w" sizes="(max-width: 1200px) 100vw, 1200px" />][5] 文件管理器，可以显示flac音频里面的专辑封面哦。 不知为何SSD的两个盘和HDD的盘图标不一样。 而且可以连接Android手机，我以为不可以来着。 [<img loading="lazy" decoding="async" class="alignnone size-full wp-image-2911" src="https://wp-archive.baka.li/2014/09/ubuntu-File-Manager.png" alt="ubuntu-File-Manager" width="855" height="664" srcset="https://wp-archive.baka.li/2014/09/ubuntu-File-Manager.png 855w, https://wp-archive.baka.li/2014/09/ubuntu-File-Manager-150x116.png 150w, https://wp-archive.baka.li/2014/09/ubuntu-File-Manager-300x232.png 300w, https://wp-archive.baka.li/2014/09/ubuntu-File-Manager-194x150.png 194w" sizes="(max-width: 855px) 100vw, 855px" />][6]

Ubuntu自带的音频播放器，可以播放Flac格式的音乐，软件本身不能设置快捷键，需要到系统设置那里设置。 [<img loading="lazy" decoding="async" class="alignnone size-full wp-image-2883" src="https://wp-archive.baka.li/2014/08/ubuntu-rhythmbox.png" alt="ubuntu-rhythmbox" width="790" height="588" srcset="https://wp-archive.baka.li/2014/08/ubuntu-rhythmbox.png 790w, https://wp-archive.baka.li/2014/08/ubuntu-rhythmbox-150x111.png 150w, https://wp-archive.baka.li/2014/08/ubuntu-rhythmbox-300x223.png 300w" sizes="(max-width: 790px) 100vw, 790px" />][7]

在linux下有个叫 <a title="wiki" href="http://zh.wikipedia.org/wiki/Wine" target="_blank">Wine</a> 的神器，可以让Ubuntu运行Windows的程序。 成功运行Foobar2000，但是全局快捷键用不了了。 Evernote也能正常运行，终于可以不用Web版的了。 [<img loading="lazy" decoding="async" class="alignnone size-full wp-image-2887" src="https://wp-archive.baka.li/2014/08/ubuntu-wine-foobar2000.png" alt="ubuntu-wine-foobar2000" width="729" height="438" srcset="https://wp-archive.baka.li/2014/08/ubuntu-wine-foobar2000.png 729w, https://wp-archive.baka.li/2014/08/ubuntu-wine-foobar2000-150x90.png 150w, https://wp-archive.baka.li/2014/08/ubuntu-wine-foobar2000-300x180.png 300w" sizes="(max-width: 729px) 100vw, 729px" />][8]

自带Firefox浏览器，Chrome有linux版的，如果没有Chrome我会不知所措的。Ubuntu下的Chrome字体渲染有些奇怪，看起来不太舒服，自动更新到了64位的Chrome 37。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-2889" src="https://wp-archive.baka.li/2014/08/ubuntu-chrome.png" alt="ubuntu-chrome" width="1280" height="720" srcset="https://wp-archive.baka.li/2014/08/ubuntu-chrome.png 1280w, https://wp-archive.baka.li/2014/08/ubuntu-chrome-150x84.png 150w, https://wp-archive.baka.li/2014/08/ubuntu-chrome-300x168.png 300w, https://wp-archive.baka.li/2014/08/ubuntu-chrome-1024x576.png 1024w" sizes="(max-width: 1280px) 100vw, 1280px" />][9] Ubuntu自带的视频播放器，播放1080P的MKV的BDRip，拖动有些慢，应付一般影音需求还是没问题的。 [<img loading="lazy" decoding="async" class="alignnone size-full wp-image-2890" src="https://wp-archive.baka.li/2014/08/ubuntu-video-player.jpg" alt="ubuntu-video-player" width="967" height="673" srcset="https://wp-archive.baka.li/2014/08/ubuntu-video-player.jpg 967w, https://wp-archive.baka.li/2014/08/ubuntu-video-player-150x104.jpg 150w, https://wp-archive.baka.li/2014/08/ubuntu-video-player-300x208.jpg 300w" sizes="(max-width: 967px) 100vw, 967px" />][10]

Ubuntu还集成了<a title="wikipedia" href="http://zh.wikipedia.org/wiki/LibreOffice" target="_blank">LibreOffice</a>办公套件，非专业人士应付下应该没问题，现在我更多的用Google Docs作表格了，同步起来方便。 [<img loading="lazy" decoding="async" class="alignnone size-full wp-image-2899" src="https://wp-archive.baka.li/2014/08/ubuntu-libreoffice.png" alt="ubuntu-libreoffice" width="1371" height="866" srcset="https://wp-archive.baka.li/2014/08/ubuntu-libreoffice.png 1371w, https://wp-archive.baka.li/2014/08/ubuntu-libreoffice-150x94.png 150w, https://wp-archive.baka.li/2014/08/ubuntu-libreoffice-300x189.png 300w, https://wp-archive.baka.li/2014/08/ubuntu-libreoffice-1024x646.png 1024w" sizes="(max-width: 1371px) 100vw, 1371px" />][11] Ubuntu自带的中文输入法很蛋疼，明明是拼音输入法设置界面确实英文的，而且很多字或词打不出来，比如“qiong”（穹）字。

好在搜狗拼音输入法有linux版，顺便说一下，在Ubuntu 14.04 LTS版本中只需要双击下载的deb包就能直接安装，在Ubuntu 12.04中安装比较繁琐，甚至我下载linux版搜狗输入法后自动弹出帮助页面介绍安装方法，不过我是没法体验这么繁琐的安装方法了，貌似安装后需要重启才能用，而且没有词库同步功能。

不过有国产厂商能发布linux的软件我已经很欣慰了。ORZ

腾讯曾开发过QQ For linux，那还是09年的时候，现在已经安装不了了。

导致Ubuntu现在没有原生的QQ客户端，只能使用Web QQ。

Web QQ没有自定义消息提示音，不能添加自定义表情，甚至不能发送图片，使用后战斗力下降998。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-2919" src="https://wp-archive.baka.li/2014/09/ubuntu-web-qq.jpg" alt="ubuntu-web-qq" width="1280" height="720" srcset="https://wp-archive.baka.li/2014/09/ubuntu-web-qq.jpg 1280w, https://wp-archive.baka.li/2014/09/ubuntu-web-qq-150x84.jpg 150w, https://wp-archive.baka.li/2014/09/ubuntu-web-qq-300x168.jpg 300w, https://wp-archive.baka.li/2014/09/ubuntu-web-qq-1024x576.jpg 1024w" sizes="(max-width: 1280px) 100vw, 1280px" />][13]

费了九牛二虎之力，终于找到了个能用的Wine QQ。

<a title="打开" href="http://www.longene.org/forum/viewtopic.php?t=4700" target="_blank">Linux兼容内核论坛 &#8211; wine qq 2013 for linux Ubuntu 64位兼容</a>

可以用全局快捷键，可以截图，可以发送图片（虽然有点麻烦），资源占用有些高。

而且经常抽，比如打不开主面板，所以我才截聊天窗口的图。

[<img loading="lazy" decoding="async" class="alignnone size-full wp-image-2923" src="https://wp-archive.baka.li/2014/09/ubuntu-QQ.jpg" alt="ubuntu-QQ" width="543" height="516" srcset="https://wp-archive.baka.li/2014/09/ubuntu-QQ.jpg 543w, https://wp-archive.baka.li/2014/09/ubuntu-QQ-150x142.jpg 150w, https://wp-archive.baka.li/2014/09/ubuntu-QQ-300x285.jpg 300w" sizes="(max-width: 543px) 100vw, 543px" />][14]

一星期用下来，感觉发行版的linux使用门坎没传说中那么高。

至少在Ubuntu中，很多快捷键甚至和Windows的一样，设置界面也比Windows的控制面板易用多了。如果再有原生QQ客户端和更多的软件，当成主力系统也不是什么问题。
